# BankApi

REST API для управления банковскими клиентами, телефонами, счетами и картами.

## Технологии

- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- Swagger

## Возможности

- CRUD клиентов, телефонов, счетов и карт
- Поиск, сортировка и пагинация клиентов
- Переводы между счетами
- Переводы между разными валютами
- Получение курсов валют KICB
- Блокировка и разблокировка карт
- Закрытие счетов с проверкой баланса и активных карт
- Валидация входных данных

## Запуск

```bash
dotnet restore
dotnet ef database update
dotnet run
